## Scoring (for the moderator, not the participant)

1. For each **odd** item (1, 3, 5, 7, 9): contribution = **score − 1**.
2. For each **even** item (2, 4, 6, 8, 10): contribution = **5 − score**.
3. Add the ten contributions (the sum is between 0 and 40).
4. Multiply the sum by **2.5**. The SUS score is between 0 and 100.

Example: answers 4, 2, 5, 1, 4, 2, 5, 1, 4, 2.
Odd items: 3 + 4 + 3 + 4 + 3 = 17. Even items: 3 + 4 + 3 + 4 + 3 = 17. Sum = 34. Score = 34 × 2.5 = **85**.

Reading the score: **68 is about average**. The V1 target is **75 or more** as the average of the five participants. With only five people, treat the number as a hint, and read the comments next to it.

Do not average the raw answers. Score each person first, then average the scores. Write the answers and the score in `notes-template.md`.
