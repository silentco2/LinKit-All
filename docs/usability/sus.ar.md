# مقياس قابلية الاستخدام (SUS)

يُعطى للمشارك بعد المهمة 4 مباشرة. اطلب منه أن يجيب بسرعة وبأول شعور يخطر له. وإن لم يكن متأكدًا فليختر الرقم الأوسط (3).

## طريقة الحساب (للمُيسِّر وليس للمشارك)

1. لكل عبارة **فردية** (1 و3 و5 و7 و9): القيمة = **الدرجة − 1**.
2. لكل عبارة **زوجية** (2 و4 و6 و8 و10): القيمة = **5 − الدرجة**.
3. اجمع القيم العشر (المجموع بين 0 و40).
4. اضرب المجموع في **2.5**. تكون درجة SUS بين 0 و100.

المتوسط العام نحو 68. هدف الإصدار الأول **75 أو أكثر** كمتوسط لدرجات المشاركين الخمسة. سجّل الإجابات والدرجة في `notes-template.md`.
