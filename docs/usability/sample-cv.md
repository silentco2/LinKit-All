# Sample CV for the study

Use this only for participants who do not want to use their own CV.
**The person, employers, schools and details below are invented.** Any resemblance to a real person is by chance. The email and phone numbers are fake.

## How to make the file

1. Open Word. Create a blank document.
2. Paste the content of the matching section below (English or Arabic).
3. Format it simply: the name in bold at the top, section titles in bold, bullets for the lists. A normal font (Calibri or Arial) is fine. For Arabic, select all text and press **Right-to-left** (Ctrl+Right Shift), and use a font such as Arial or Tahoma.
4. Save as `Sample CV.docx` (or `السيرة الذاتية النموذجية.docx` for Arabic) on the desktop of the study machine.
5. Delete the file at the end of the session.

Do not use a real person's CV as a "sample". Do not edit the facts to match the participant: if they want to say "this is me", ask them to use their own CV.
