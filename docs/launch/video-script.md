# 30–45 s vertical video (LinkedIn and X native)

Record 1080 × 1920 (or crop a 1280 × 800 recording to the middle). Use the made-up study data
(`uv run python scripts/seed_usability.py --data-dir <folder>` prints the command that starts the app on it) so no real
CV, email or company shows. Captions on screen: most people watch muted.

| Time | Screen | Caption |
|---|---|---|
| 0–3 s | Home with the funnel counts | "My job hunt, on autopilot. On my own computer." |
| 3–8 s | Setup: drop a CV, pick an AI (show the Ollama option) | "Bring your own AI. Even a local one." |
| 8–15 s | Jobs list scrolling, open one: AI score 9/10 with reasons | "295 sources, ranked against my CV." |
| 15–22 s | Tailoring red-line view: two or three words changed | "It changes a few words. Never my employers, dates or numbers." |
| 22–32 s | The app browser filling a practice form step by step | "It fills in the application…" |
| 32–38 s | Needs you: one answer for four applications | "…and asks me what only I should answer." |
| 38–45 s | Practice-mode screenshot, then the GitHub page | "Free and open source. Link in the comments." |

End card: logo, "LinKit All", `uv tool install linkit-all`.
