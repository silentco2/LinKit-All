## Arabic developer communities

Post the Arabic text from [linkedin-ar.md](linkedin-ar.md); adapt per group.

- LinkedIn: your own network first, then Arabic tech groups you are already a member of.
- Facebook: Egyptian and Arab developer groups you already belong to (for example "Python Egypt" and similar regional groups). Read each group's self-promotion rule.
- Telegram: Arabic programming channels you follow; ask the admin before posting.
- Hsoub I/O (io.hsoub.com): an Arabic community with a programming section.
- Dev Arabic newsletters you subscribe to: send the maintainer a short note with the link.

Only post where you are a real member; a cold drop in a group you never joined reads as spam.
